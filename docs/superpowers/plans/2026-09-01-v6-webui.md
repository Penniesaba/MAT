# v6.0 Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `webui` subcommand that serves a tailscale-style monochrome web UI for configuring, running, and monitoring parallel repository analysis.

**Architecture:** A new lib crate `mcp-sec-audit-webui` (axum server + embedded static assets) sits beside cli/core in the `rust/` workspace. It calls `mcp-sec-audit-core` in-process and receives structured progress through a new `EventSink` (a `broadcast` of `AnalysisEvent`s) threaded through `RunContext`; the pipeline emits hierarchical `StageProgress` events at its stage boundaries, and a webui-side tracing `Layer` captures per-repo log lines into the same stream.

**Tech Stack:** Rust 2024, axum 0.8 (ws), tokio broadcast, tracing, serde, embedded HTML/CSS/JS (no npm).

**Spec:** `docs/superpowers/specs/2026-09-01-v6-webui-design.md`

## Global Constraints

- Workspace: `rust/` (edition `2024`, rust-version `1.88`); new crate at `rust/crates/mcp-sec-audit-webui/`.
- `serde` stays pinned `=1.0.224` (swc_core 0.101 re-export constraint — do not bump).
- The single-repo CLI path (`run_static_scan_async` via `run_static_scan_inner`) must remain **byte-identical** when no subscriber exists: `EventSink::noop()` drops every event.
- `webui` is a CLI subcommand, sibling to `Batch`/`Bench`; run via `cargo run -- webui`.
- UI is **pure black/white/gray** (no color); detail modal is 1/3 page width × 4/5 page height, centered.
- Event enum variants are `#[derive(Clone, Serialize, Deserialize)]` (broadcast + JSON over WS both need it).

        Phase2(Phase2Step::Standard(Phase2StandardStep::Taint)) => 52,

/// Cloneable event producer. `None` sender = noop (single-repo CLI path).
#[derive(Clone)]
pub struct EventSink {
    tx: Option<broadcast::Sender<AnalysisEvent>>,
    repo: Option<String>,
}

impl EventSink {
    pub fn noop() -> Self {
        Self { tx: None, repo: None }
    }

    /// Returns a sink plus the receiver subscribers use.
    pub fn broadcast() -> (Self, broadcast::Receiver<AnalysisEvent>) {
        let (tx, rx) = broadcast::channel(256);
        (Self { tx: Some(tx), repo: None }, rx)
    }

    /// Returns a sink that stamps `repo` onto every repo-attributed event.
    pub fn scoped(&self, repo: &str) -> Self {
        Self { tx: self.tx.clone(), repo: Some(repo.to_string()) }
    }

    pub fn emit(&self, event: AnalysisEvent) {
        if let Some(tx) = &self.tx {
            let _ = tx.send(event);
        }
    }

    pub fn stage_progress(&self, stage: Stage, percent: u8) {
        self.emit(AnalysisEvent::StageProgress {
            repo: self.repo.clone().unwrap_or_default(),
            stage,
            percent,
        });
    }

    pub fn log(&self, level: LogLevel, line: impl Into<String>) {
        self.emit(AnalysisEvent::Log {
            repo: self.repo.clone().unwrap_or_default(),
            level,
            line: line.into(),
        });
    }
}

        let (sink, mut rx) = EventSink::broadcast();

async fn run_batch_emits_lifecycle_events() {

    let mut saw_started = false;
    let mut saw_repo_a = false;
    let mut saw_finished = false;
    while let Ok(ev) = rx.try_recv() {
        match ev {
            AnalysisEvent::BatchStarted { .. } => saw_started = true,
            AnalysisEvent::RepoStarted { repo } if repo == "a" => saw_repo_a = true,
            AnalysisEvent::BatchFinished { .. } => saw_finished = true,
            _ => {}
        }
    }
    assert!(saw_started, "no BatchStarted");
    assert!(saw_repo_a, "no RepoStarted(a)");
    assert!(saw_finished, "no BatchFinished");

    Single(RuntimeConfig),
    Batch(BatchConfig),
}

/// Parse a TOML document as a batch config first (a batch file is a superset of
/// the runtime config), falling back to a single-repo runtime config.
pub fn parse_config(input: &str) -> Result<ConfigKind> {
    // A batch config carries a top-level `[batch]` table (possibly empty).
    match mcp_sec_audit_core::parse_batch_config_toml(input) {
        Ok(batch) if !batch.batch.repos.is_empty() || contains_batch_table(input) => {
            Ok(ConfigKind::Batch(batch))
        }
        Ok(_) | Err(_) => {
            let runtime = mcp_sec_audit_core::parse_runtime_config_toml(input)
                .context("parse as runtime config")?;
            Ok(ConfigKind::Single(runtime))
        }
    }
}

fn contains_batch_table(input: &str) -> bool {
    input.lines().any(|l| l.trim_start().starts_with("[batch]"))
}

pub fn render_config(config: &ConfigKind) -> Result<String> {
    match config {
        ConfigKind::Single(r) => toml::to_string_pretty(r).context("serialize runtime config"),
        ConfigKind::Batch(b) => toml::to_string_pretty(b).context("serialize batch config"),
    }
}

pub fn config_as_json(config: &ConfigKind) -> Result<serde_json::Value> {

        ConfigKind::Single(r) => serde_json::to_value(r)?,

//! Run state: per-repo progress, bounded log buffers, and snapshot for WS replay.

use std::collections::BTreeMap;

use mcp_sec_audit_core::batch::RepoStatus;
use mcp_sec_audit_core::events::AnalysisEvent;
use tokio::sync::broadcast;
use tokio_util::sync::CancellationToken;

/// Fixed-capacity ring buffer of log lines per repo.
#[derive(Debug, Clone, Default)]
pub struct RingBuffer<T> {
    items: Vec<T>,
    cap: usize,
}

impl<T> RingBuffer<T> {
    pub fn new(cap: usize) -> Self {
        Self { items: Vec::with_capacity(cap), cap: cap.max(1) }
    }
    pub fn push(&mut self, item: T) {
        if self.items.len() == self.cap {
            self.items.remove(0);
        }
        self.items.push(item);
    }
    pub fn iter(&self) -> impl Iterator<Item = &T> {
        self.items.iter()
    }
    pub fn len(&self) -> usize {
        self.items.len()
    }
}

/// Live progress of one repo.

pub struct RepoProgress {
    pub status: RepoStatus,
    pub stage: Option<Stage>,
    pub percent: u8,

    pub finding_count: Option<usize>,

#[derive(Clone)]
pub struct RunManager {
    tx: broadcast::Sender<AnalysisEvent>,
    cancel: CancellationToken,
    state: std::sync::Arc<std::sync::Mutex<ManagerState>>,
}

struct ManagerState {
    batch_id: Option<String>,
    repos: BTreeMap<String, RepoProgress>,
    logs: BTreeMap<String, RingBuffer<(String, String)>>,
    finished: bool,
}

impl RunManager {
    pub fn new() -> Self {
        let (tx, _) = broadcast::channel(256);
        Self {
            tx,
            cancel: CancellationToken::new(),
            state: std::sync::Arc::new(std::sync::Mutex::new(ManagerState {
                batch_id: None,
                repos: BTreeMap::new(),
                logs: BTreeMap::new(),
                finished: false,
            })),
        }
    }

    pub fn cancel_token(&self) -> CancellationToken {
        self.cancel.clone()
    }

    /// A receiver that yields future events (for live WS forwarding).
    pub fn subscribe(&self) -> broadcast::Receiver<AnalysisEvent> {
        self.tx.subscribe()
    }

    /// The sender used to broadcast events to subscribers.
    pub fn sender(&self) -> broadcast::Sender<AnalysisEvent> {
        self.tx.clone()
    }

    /// Fold one event into the managed state, then re-broadcast it to
    /// subscribers (the single consumption point: WS clients read the snapshot
    /// on connect, then live events from `subscribe()`).
    pub fn record(&self, event: AnalysisEvent) {
        let mut state = self.state.lock().expect("run state mutex");
        match &event {
            AnalysisEvent::BatchStarted { batch_id, repo_names, .. } => {
                state.batch_id = Some(batch_id.clone());
                for name in repo_names {
                    state.repos.entry(name.clone()).or_default();
                }
            }
            AnalysisEvent::RepoStarted { repo } => {
                state.repos.entry(repo.clone()).or_default();
            }
            AnalysisEvent::StageProgress { repo, stage, percent } => {
                let p = state.repos.entry(repo.clone()).or_default();
                p.stage = Some(stage.clone());
                p.percent = *percent;
            }
            AnalysisEvent::RepoFinished { repo, status, duration_ms: _, risk_level, fused_finding_count } => {
                let p = state.repos.entry(repo.clone()).or_default();
                p.status = *status;
                p.risk_level = risk_level.clone();
                p.finding_count = *fused_finding_count;
            }
            AnalysisEvent::Log { repo, level, line } => {
                let buf = state.logs.entry(repo.clone()).or_insert_with(|| RingBuffer::new(500));
                buf.push((level_to_str(*level).to_string(), line.clone()));
            }
            AnalysisEvent::BatchFinished { .. } => {
                state.finished = true;
            }
        }
        let _ = self.tx.send(event);
    }

    pub fn snapshot(&self) -> RunSnapshot {
        let state = self.state.lock().expect("run state mutex");
        RunSnapshot {
            batch_id: state.batch_id.clone(),
            repos: state.repos.clone(),
            logs: state
                .logs
                .iter()
                .map(|(k, v)| (k.clone(), v.iter().cloned().collect()))
                .collect(),
        }
    }
}

impl Default for RunManager {
    fn default() -> Self {
        Self::new()
    }
}

    use mcp_sec_audit_core::LogLevel::*;
    match level {
        Trace => "trace",
        Debug => "debug",
        Info => "info",
        Warn => "warn",
        Error => "error",
    }

//! Launch a scan (batch or single) and pipe its events into the RunManager.

use anyhow::Result;
use mcp_sec_audit_core::events::EventSink;
use mcp_sec_audit_core::runctx::Progress;
use mcp_sec_audit_core::{BatchConfig, RuntimeConfig, RunContext, RunId, run_batch, run_static_scan_async};

use crate::state::RunManager;

/// A single active run. `handle` is the join handle of the driving task.
pub struct ActiveRun {
    pub handle: tokio::task::JoinHandle<()>,
}

/// Start a batch run. The returned task drives `run_batch`, recording every
/// event through `manager.record`.
pub fn start_batch(manager: RunManager, batch: BatchConfig) -> ActiveRun {
    let mgr = manager.clone();
    let cancel = manager.cancel_token();
    let handle = tokio::spawn(async move {
        let (events, mut rx) = EventSink::broadcast();
        // Forward every emitted event into the manager (record + rebroadcast).
        let fwd = manager.clone();
        let forwarder = tokio::spawn(async move {
            while let Ok(ev) = rx.recv().await {
                fwd.record(ev);
            }
        });

        let result = run_batch(batch, cancel, events).await;
        // Drain whatever the forwarder may still be reading, then let it finish.
        drop(mgr);
        let _ = forwarder.await;
        let _ = result;
    });
    ActiveRun { handle }
}

/// Start a single-repo run (target = `config.scan.targets`).
pub fn start_single(manager: RunManager, config: RuntimeConfig) -> ActiveRun {
    let mgr = manager.clone();
    let cancel = manager.cancel_token();
    let handle = tokio::spawn(async move {
        let (events, mut rx) = EventSink::broadcast();
        let fwd = manager.clone();
        let forwarder = tokio::spawn(async move {
            while let Ok(ev) = rx.recv().await {
                fwd.record(ev);
            }
        });

        let run_ctx = RunContext::for_repo(
            RunId::new(),
            Progress::noop(),
            events.scoped("single"),
            cancel,
            None,
            None,
        );
        let result = run_static_scan_async(&config, &[], None, &run_ctx).await;
        drop(mgr);
        let _ = forwarder.await;
        let _ = result;
    });
    ActiveRun { handle }
}

use axum::extract::ws::{Message, WebSocket, WebSocketUpgrade};
use axum::extract::State;
use axum::response::Response;
use mcp_sec_audit_core::events::AnalysisEvent;

use crate::state::RunManager;

pub async fn ws_handler(
    ws: WebSocketUpgrade,
    State(manager): State<RunManager>,
) -> Response {
    ws.on_upgrade(move |socket| handle_socket(socket, manager))
}

async fn handle_socket(mut socket: WebSocket, manager: RunManager) {
    // 1. Send snapshot as the first frame (JSON envelope).
    let snapshot = serde_json::json!({
        "type": "snapshot",
        "data": manager.snapshot(),
    });
    if socket.send(Message::Text(snapshot.to_string())).await.is_err() {
        return;
    }

    // 2. Stream live events.
    let mut rx = manager.subscribe();
    loop {
        tokio::select! {
            maybe = rx.recv() => {
                match maybe {
                    Ok(ev) => {
                        let frame = serde_json::json!({ "type": "event", "data": ev });
                        if socket.send(Message::Text(frame.to_string())).await.is_err() {
                            return;
                        }
                    }
                    Err(broadcast::error::RecvError::Lagged(_)) => continue,
                    Err(broadcast::error::RecvError::Closed) => return,
                }
            }
            msg = socket.recv() => {
                // Ignore incoming pings/close; just keep serving until close.
                match msg {
                    None | Some(Ok(Message::Close(_))) => return,
                    _ => {}
                }
            }
        }
    }
}

//! A tracing Layer that captures log lines into the event stream as `Log`.

use mcp_sec_audit_core::events::AnalysisEvent;
use mcp_sec_audit_core::LogLevel;
use tracing::Event;
use tracing::field::Visit;
use tracing_subscriber::Layer;
use tracing_subscriber::layer::Context;
use tracing_subscriber::registry::LookupSpan;

use crate::state::RunManager;

pub struct CaptureLayer {
    manager: RunManager,
}

impl CaptureLayer {
    pub fn new(manager: RunManager) -> Self {
        Self { manager }
    }
}

impl<S> Layer<S> for CaptureLayer
where
    S: tracing::Subscriber + for<'a> LookupSpan<'a>,
{
    fn on_event(&self, event: &Event<'_>, _ctx: Context<'_, S>) {
        let mut v = MsgVisitor { message: String::new(), repo: None };
        event.record(&mut v);

        let level = match *event.metadata().level() {
            tracing::Level::ERROR => LogLevel::Error,
            tracing::Level::WARN => LogLevel::Warn,
            tracing::Level::INFO => LogLevel::Info,
            tracing::Level::DEBUG => LogLevel::Debug,
            tracing::Level::TRACE => LogLevel::Trace,
        };

        // Repo attribution: walk spans for a `repo` field (same idea as the
        // CLI's ModuleFormat::repo_from_context). Keep it simple: if any span
        // records `repo=<name>`, use it; else empty.
        let mut repo = String::new();
        let _ = _ctx.scope().from_root().try_for_each(|span| {
            // (repo extraction is span-visitor based; see note below)
            Ok::<(), ()>(())
        });

        let event = AnalysisEvent::Log {
            repo: v.repo.unwrap_or(repo),
            level,
            line: v.message,
        };
        self.manager.record(event);
    }
}

struct MsgVisitor {
    message: String,
    repo: Option<String>,
}

impl Visit for MsgVisitor {
    fn record_debug(&mut self, field: &tracing::field::Field, value: &dyn std::fmt::Debug) {
        if field.name() == "message" {
            self.message = format!("{value:?}");
        }
        if field.name() == "repo" {
            self.repo = Some(format!("{value:?}"));
        }
    }
}
```

> Note on repo attribution: the tracing `event.record` only sees fields on the *event itself*, not ancestor spans. Pipeline `Log`-worthy lines are emitted either as `Progress::report` (already event-stream via `EventSink::log` in Task 10 wiring, not here) or as `tracing::info!` inside a `repo` span. To attribute span-carried repo, the CLI reuses `ctx.visit_spans` + `FormattedFields`. For v6, keep the first version simple: attribute repo via the event's own `repo` field when present (the orchestrator's `run_repo` enters `info_span!("repo", repo=%name)` but does NOT add `repo` to each event's fields). Therefore the primary per-repo detail channel is `EventSink::log` (Task 10), and this Layer is a best-effort supplement for `tracing::info!` lines without repo (repo stays empty). Document this limitation in the task's commit message.

//! axum router: config CRUD + import/export + run + WS.

use std::net::SocketAddr;
use std::sync::{Arc, Mutex};

use anyhow::Result;
use axum::Router;
use axum::extract::State;
use axum::http::StatusCode;
use axum::response::{Html, IntoResponse};
use axum::routing::{get, post};
use serde::Deserialize;

use crate::events;
use crate::log_capture::CaptureLayer;
use crate::run;
use crate::state::RunManager;
use crate::toml_import::{ConfigKind, parse_config, render_config};

#[derive(Clone)]
pub struct AppState {
    manager: RunManager,
    config: Arc<Mutex<Option<ConfigKind>>>,
}

pub fn build_router() -> Router {
    let state = AppState {
        manager: RunManager::new(),
        config: Arc::new(Mutex::new(None)),
    };
    Router::new()
        .route("/", get(index))
        .route("/api/config", get(get_config).put(put_config))
        .route("/api/import", post(import))
        .route("/api/config/export", get(export))
        .route("/api/run", post(api_run))
        .route("/api/run/cancel", post(cancel))
        .route("/ws/events", get(events::ws_handler))
        .with_state(state)
}

async fn index() -> Html<&'static str> {
    Html(include_str!("../static/index.html"))
}

async fn get_config(State(state): State<AppState>) -> impl IntoResponse {
    let cfg = state.config.lock().expect("config mutex");
    match cfg.as_ref() {
        Some(c) => serde_json::to_string(c).map(|s| (StatusCode::OK, s)).unwrap(),
        None => (StatusCode::OK, "null".to_string()),
    }
}

async fn put_config(State(state): State<AppState>, body: String) -> impl IntoResponse {
    match parse_config(&body) {
        Ok(c) => {
            *state.config.lock().expect("config mutex") = Some(c);
            (StatusCode::OK, "ok".to_string())
        }
        Err(e) => (StatusCode::BAD_REQUEST, format!("invalid config: {e:#}")),
    }
}

async fn import(State(state): State<AppState>, body: String) -> impl IntoResponse {
    match parse_config(&body) {
        Ok(c) => {
            *state.config.lock().expect("config mutex") = Some(c);
            (StatusCode::OK, render_config(state.config.lock().unwrap().as_ref().unwrap()).unwrap_or_default())
        }
        Err(e) => (StatusCode::BAD_REQUEST, format!("invalid config: {e:#}")),
    }
}

async fn export(State(state): State<AppState>) -> impl IntoResponse {
    let cfg = state.config.lock().expect("config mutex");
    match cfg.as_ref() {
        Some(c) => (StatusCode::OK, render_config(c).unwrap_or_default()),
        None => (StatusCode::NOT_FOUND, "no config loaded".to_string()),
    }
}

async fn api_run(State(state): State<AppState>) -> impl IntoResponse {
    let cfg = state.config.lock().expect("config mutex").clone();
    match cfg {
        Some(ConfigKind::Batch(b)) => {
            let _ = run::start_batch(state.manager.clone(), b);
            (StatusCode::ACCEPTED, "started batch".to_string())
        }
        Some(ConfigKind::Single(r)) => {
            let _ = run::start_single(state.manager.clone(), r);
            (StatusCode::ACCEPTED, "started single".to_string())
        }
        None => (StatusCode::BAD_REQUEST, "no config loaded".to_string()),
    }
}

async fn cancel(State(state): State<AppState>) -> impl IntoResponse {
    state.manager.cancel_token().cancel();
    (StatusCode::OK, "cancel requested".to_string())
}
```

```js
const $ = (id) => document.getElementById(id);
let ws = null;
const logs = new Map(); // repo -> array of lines
const repos = new Map(); // repo -> element

function connect() {
  ws = new WebSocket(`${location.protocol === 'https:' ? 'wss' : 'ws'}://${location.host}/ws/events`);
  ws.onmessage = (e) => {
    const msg = JSON.parse(e.data);
    if (msg.type === 'snapshot') renderSnapshot(msg.data);
    else if (msg.type === 'event') handleEvent(msg.data);
  };
  ws.onclose = () => setTimeout(connect, 1000);
}

function handleEvent(ev) {
  if (ev.BatchStarted) { ev.BatchStarted.repo_names.forEach(ensureRepo); return; }
  if (ev.RepoStarted) { ensureRepo(ev.RepoStarted.repo); return; }
  if (ev.StageProgress) {
    const r = ensureRepo(ev.StageProgress.repo);
    r.querySelector('.fill').style.width = ev.StageProgress.percent + '%';
    r.querySelector('.repo-status').textContent = `${ev.StageProgress.percent}%`;
    return;
  }
  if (ev.Log) {
    const repo = ev.Log.repo;
    if (!logs.has(repo)) logs.set(repo, []);
    logs.get(repo).push(`${ev.Log.level}: ${ev.Log.line}`);
    if ($('modal').hidden === false && $('modal-title').textContent === repo) renderModal(repo);
  }
  if (ev.RepoFinished) {
    const r = ensureRepo(ev.RepoFinished.repo);
    r.classList.add(ev.RepoFinished.status === 'ok' ? 'done' : 'failed');
    r.querySelector('.repo-status').textContent = ev.RepoFinished.status;
  }
}

function renderSnapshot(snap) {
  for (const [name, p] of Object.entries(snap.repos || {})) {
    const r = ensureRepo(name);
    r.querySelector('.fill').style.width = (p.percent || 0) + '%';
    r.querySelector('.repo-status').textContent = p.status || `${p.percent}%`;
  }
  for (const [name, lines] of Object.entries(snap.logs || {})) {
    logs.set(name, lines.map(([lvl, l]) => `${lvl}: ${l}`));
  }
}

function ensureRepo(name) {
  if (repos.has(name)) return repos.get(name);
  const el = document.createElement('div');
  el.className = 'repo';
  el.innerHTML = `<div class="repo-head"><span class="repo-name"></span><span class="repo-status"></span></div><div class="bar"><div class="fill"></div></div>`;
  el.querySelector('.repo-name').textContent = name;
  el.onclick = () => openModal(name);
  $('repos').appendChild(el);
  repos.set(name, el);
  return el;
}

function openModal(name) {
  $('modal').hidden = false;
  $('modal-title').textContent = name;
  renderModal(name);
}
function renderModal(name) {
  $('modal-logs').textContent = (logs.get(name) || []).join('\n');
}
$('modal-close').onclick = () => { $('modal').hidden = true; };

$('import-btn').onclick = () => $('file').click();
$('file').onchange = async () => {
  const text = await $('file').files[0].text();
  $('toml').value = text;
  importToml(text);
};
async function importToml(text) {
  const r = await fetch('/api/import', { method: 'POST', body: text });
  const err = $('config-error');
  if (!r.ok) { err.hidden = false; err.textContent = await r.text(); }
  else { err.hidden = true; }
}
$('export-btn').onclick = async () => {
  const r = await fetch('/api/config/export');
  const text = await r.text();
  $('toml').value = text;
};
$('run-btn').onclick = async () => {
  const text = $('toml').value;
  if (text.trim()) await importToml(text);
  await fetch('/api/run', { method: 'POST' });
};

connect();
```
